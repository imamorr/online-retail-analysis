Чтобы код работал, необходимо иметь установленными библиотеки pandas, matplotlib, openpyxl.
Их можно установить через терминал с помощью команды pip install "имя библиотеки", если они еще не установлены.
Посмотреть установлена библиотека или нет можно в терминале с помощью команды pip show "имя библиотеки".

Сам код написан в файле с расширением .ipynb, поэтому чтобы его просмотреть и выполнить надо иметь редактор кода
jupyter notebook или расширение jupyter для vscode, в случае с vscode так же надо установить вычислительное ядро
через терминал с помощью pip install jupyter.

Также необходимо загрузить датасет из прилагаемого файла "Onlineretail.xlsx" и поместить его в нужную директорию.
Проще всего это сделать, скопировав репозиторий через терминал с помощью git clone https://github.com/imamorr/online-retail-analysis ,
однако для этого нужно иметь установленный git.
