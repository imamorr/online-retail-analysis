# analisys_project

## Разбор ключевых обозначений в столбцах
В столбце 'StockCode' есть товары с кодом 'POST', 'D', 'C2', 'DOT', 'M', 'S', 'm', 'PADS', 'B', 'CRUK', 'BANK CHARGES', 'AMAZONFEE', которые влияют на общую выручку, но не относятся к продажам определенных товаров.
В столбце 'Description' также есть много служебных записей типа 'wet pallet', 'test', '???', 'DAMAGED' и тому подобные. Анализ показал, что такие описания встречаются редко и практически не влияют на выручку компании.

## Анализ прибыли по товарам / месяцам
Выручка за весь период составила 9747747.934 фунтов.
Самым прибыльным месяцем был Ноябрь. Вся выручка составила 1461756.250 фунтов. Было продано 740286 товаров с учетом товаров, потерь и прочего.
Наименее прибыльным месяцем был апрель. Выручка за этот месяц стоставила 493207.121 фунт, что меньше примерно на 66.26% по сравнению с ноябрем.
